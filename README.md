# つるい未来補助金 事業計画ヒアリングフォーム

PC・スマートフォン・タブレットから利用できる、つるい未来補助金の事業者向けヒアリングフォームです。
ログイン不要で、リンクを開くだけでご利用いただけます。設計は「小規模事業者持続化補助金ヒアリングフォーム」
（`hojokin-hearing-forms`）に準じています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 類型A・B・Cを選ぶトップページ |
| `ruikei-a.html` | 類型A 新規開業・新分野進出支援事業（全14ブロック＋提出書類、最大115問） |
| `ruikei-b.html` | 類型B 事業継続支援事業（全11ブロック＋提出書類、最大103問） |
| `ruikei-c.html` | 類型C 観光推進事業（全15ブロック＋提出書類、最大114問） |
| `tools/` | 元のExcelからHTMLを生成するスクリプト（下記） |

## 使い方

GitHub Pagesで公開し、`index.html` のURLを事業者様に共有してください。
回答は各自の端末（ブラウザのlocalStorage）に自動保存され、サーバーには一切送信されません。
最後の「確認・保存」画面でCSV（Excel「回答一覧（支援者・AI読み込み用）」と同じ列構成）または
テキストとして保存・コピーできます。別端末への引き継ぎは、進捗ファイルまたはQR/リンクで行えます。

## 参照元Excelとの対応

- 設問文・記入例・選択肢・「対象外」になる分岐条件は、Excelの各シート（設問ID・おたずね・記入例・
  入力規則・状態列の数式）から自動抽出しています。
- Excelの「対象外／先に選択」は、Webでは「表示しない」で表現しています。分岐元の設問に回答すると
  該当する設問が現れ、全設問が対象外になったブロックは「次へ／戻る」で自動的に飛ばされます。
- Excelの「提出書類チェック」は最終ブロックの手前に置いています（準備済み／準備中／まだ／該当なし＋備考）。

## 更新方法

```
python tools/extract.py   # Excel(リポジトリ外に保管) -> tools/spec_*.json
python tools/build.py     # spec_*.json -> index.html / ruikei-*.html
python tools/test/smoke.py  # Chromeでの通し動作確認（要 playwright）
```

- 返送先・締切を表紙に表示するには `tools/config.json`（`{"returnTo":"…","deadline":"…"}`）を作成して
  `build.py` を再実行します。未設定なら表示されません。
- 表紙の補助金概要は補助規則（別表1）に基づき `tools/build.py` の `TYPES` に記載しています。
  規則が改正された場合はここを更新してください。
- 生成物（HTML）は直接編集せず、`tools/` 配下のテンプレート・スクリプトを編集してください。

## Excelとの差分（`tools/build.py` で吸収）

Excel本体は未改訂のため、以下はビルド時に反映しています（`REMOVE_IDS` / `EXTRA_QUESTIONS`）。

- 類型C: 観光推進事業は補助限度額の加算がないため、C1-06〜C1-09（指定区域・空き家・居住歴・年齢）を削除
- 類型B: 補助対象経費の報償費（B5-21〜B5-24）・広告宣伝費（B5-25〜B5-28）の設問を追加
